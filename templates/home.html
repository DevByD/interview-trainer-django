Security Architecture

Assessment Security & Test Integrity

Built with robust client-side event detection and server-authoritative state management.

📷 Camera Verification

Pre-assessment hardware readiness verification ensuring camera hardware is active and functional.

🎙️ Microphone Verification

Pre-assessment audio input verification testing device connectivity without recording audio.

🖥️ Fullscreen Enforcement

Detects fullscreen exit events immediately with warning dialogues prompting instant return.

👀 Tab-Switch Detection

Tracks window blur and tab switching events in real-time, logging violation timestamps to the backend.

⚠️ Three-Warning System

Enforces an authoritative 3-warning threshold with automatic submission on the fourth violation.

🔒 Server-Side Assessment State

Assessment deadlines and violation counts are computed server-side to prevent client-side clock tampering.
